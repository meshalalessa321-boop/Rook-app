What Rook is today

Rook Zero is our small language-model experiment. The neural network begins from random initialization and uses its own learned weights for generation.

What this app does

Runs the model in this browser, saves conversations locally, and provides a separate notebook for manually saved memory. It does not call an external AI API.

What it does not do yet

It does not train its neural network in the browser, learn automatically from every conversation, or sync data across devices. Persistent training and safe model upgrades are later engineering steps.

Privacy

Chat and memory are stored in this browser's local storage. Anyone with access to this browser profile may be able to see them. Export backups before clearing browser data.
